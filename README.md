## 🛡️ About Me

I am an **Information Assurance student at FPT University** focused on Security Operations, threat detection, and incident response. I build hands-on SOC environments that connect endpoint, network, firewall, IDS/IPS, and PowerShell telemetry to detection, enrichment, and case-management workflows.

- 🔎 Investigating alerts across endpoint and network telemetry
- 🧠 Building and tuning detections with SPL, Sigma, YARA, and MITRE ATT&CK
- ⚙️ Automating alert enrichment, risk scoring, deduplication, and incident workflows
- 🧪 Validating detections with Atomic Red Team and attack simulations
- 🎯 Seeking a **SOC Analyst Intern** opportunity

## 🎯 SOC Focus

| Area | Practical focus |
|---|---|
| **Security Monitoring & Triage** | Alert validation, severity assessment, IOC analysis, false-positive reduction |
| **Detection Engineering** | SPL correlation searches, Sigma rules, risk scoring, normalization, deduplication |
| **Incident Response** | Evidence collection, timeline analysis, case documentation, response workflows |
| **Threat Hunting & Forensics** | Endpoint telemetry, packet analysis, memory/disk artifacts, malware behavior |
| **Security Automation** | Webhooks, API enrichment, SOAR playbooks, repeatable analyst workflows |
